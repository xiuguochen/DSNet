# DSNet
The code is located in the "code" folder, where the "UNet_Module.py" file contains the network part. Please make sure to modify the PSF when using it.
The data is located in the "data" folder, including pre-training data and fine-tuning data.
The models are located in the "model" folder, including both the pre-trained and fine-tuned models.
